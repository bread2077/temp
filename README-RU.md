# Общий калькулятор SMMPrime

## Первая установка

1. Распакуйте архив на компьютере.
2. Откройте репозиторий https://github.com/bread2077/temp и ветку main.
3. Через Add file → Upload files загрузите папку **calculator целиком** в корень репозитория. В репозитории должны получиться:
   - calculator/loader-v1.js
   - calculator/manifest.json
   - calculator/releases/2026-10-05-1/calculator.js
   - calculator/releases/2026-10-05-1/calculator.css
   - calculator/releases/2026-10-05-1/catalog.json
4. Сохраните загрузку кнопкой Commit changes. Не загружайте ZIP вместо распакованных файлов.
5. После публикации файлов замените код главной содержимым install/homepage.txt, а код страницы /calc — содержимым install/calc-page.txt.
6. Проверьте главную без входа и /calc после входа: выбор соцсети, услуги и параметров, кнопку, мобильную версию.

**До загрузки папки calculator новый код страниц устанавливать не нужно.** Пока файлы не опубликованы, калькулятор показывает сообщение о недоступности и ссылку на услуги.

install/homepage.txt подготовлен по последнему варианту главной из этой беседы. Если вы меняли главную после него, используйте install/guest-snippet.txt вместо замены всей страницы: удалите старый калькулятор, его стили и его отдельный скрипт, вставьте блок в нужное место. Сохраните остальные изменения страницы.

## Добавить на другую страницу

Вставьте install/guest-snippet.txt в нужное место. Для личного кабинета используйте install/account-snippet.txt.
Настройки блока:

| Атрибут | Значения |
| --- | --- |
| data-mode | guest — кнопка регистрации /signup; account — выбранная услуга |
| data-title | true — заголовок «Калькулятор услуг», false — без заголовка |
| data-switcher | true — переключатель «Выбор Услуги / Умный Подбор», false — без переключателя |

Скрипт подключается один раз на странице. Повторное подключение не дублирует калькулятор. Можно поставить несколько блоков: выбор внутри каждого независим, последнее изменение сохраняется в общем хранилище браузера.

Оформление изолировано через Shadow DOM, чтобы стили других страниц не искажали калькулятор. Шрифт наследуется от сайта. На ПК используется форма /calc, на телефоне — выпадающие списки.

## Как обновлять

Не редактируйте файлы уже опубликованной папки версии: CDN может продолжить отдавать старые данные.

1. Подготовьте новую папку, например calculator/releases/2026-10-06-1/.
2. В ней должны быть все три файла: calculator.js, calculator.css, catalog.json.
3. Загрузите эту новую папку в GitHub.
4. Проверьте доступность всех трёх файлов через https://cdn.jsdelivr.net/gh/bread2077/temp@main/calculator/releases/2026-10-06-1/ с нужным именем файла в конце.
5. Затем в calculator/manifest.json замените release на 2026-10-06-1 и сохраните.

На страницах ничего менять не нужно. Новые версии подхватываются при следующем открытии или перезагрузке страницы, а не посреди заполнения.
Обновление не гарантируется мгновенно: публикация GitHub и промежуточные кэши могут задерживать новый manifest. Загрузчик запрашивает manifest напрямую через raw.githubusercontent.com без браузерного кэша; файлы каждой версии имеют новые адреса CDN.

loader-v1.js — постоянный загрузчик. Его не требуется менять при обычных обновлениях каталога, логики и оформления. Существенное изменение самого протокола загрузки может потребовать нового загрузчика и замены подключения.

Можно подготовить новую версию автоматически, если установлен Python:

    python3 prepare-release.py 2026-10-06-1 new-catalog.json

Команда копирует текущую версию, проверяет и заменяет каталог, обновляет локальный manifest. Она ничего не публикует. Без Python файлы можно обновить вручную либо попросить подготовить следующий пакет.

## Откат

Верните предыдущий номер в manifest.json. Старые папки версий не удаляйте.
Если новая версия не загружается, загрузчик пробует последнюю успешно загруженную в этом браузере; для нового браузера запасная версия — 2026-10-05-1. При общей недоступности ресурсов показываются ссылка на услуги и кнопка повторной загрузки.

## Данные и цены

Начальный каталог: 443 записи, 16 соцсетей, снимок таблицы от 05.10.2026.
Google Sheets пока не синхронизируется автоматически: изменения таблицы нужно включать в новый catalog.json.
Цены, как и раньше, обновляются с /services на текущем домене. При недоступности используются цены каталога с пояснением. Для услуг без цены в каталоге цена появится только при успешном получении с /services.
API-ключи не нужны. JSON публичен: храните в нём только информацию об услугах.
Выбор сохраняется в браузере; это не создание заказа и не гарантированный перенос услуги в форму заказа после регистрации.

## Проверка перед публикацией

В пакете выполнены проверка синтаксиса JS, подбор всех 443 услуг для обоих режимов, ссылки кнопок, сценарии загрузчика и восстановления сохранённого выбора. Визуальную проверку на вашем сайте нужно выполнить после загрузки: эти файлы ещё не опубликованы.
