SMMPrime v12 — единый комплект для мобильной главной

ПОРЯДОК УСТАНОВКИ
1. Сохраните текущие layout v11 и главную для отката.
2. Распакуйте github-assets-v12.zip. Загрузите папку assets/smmprime-speed-v12
   в репозиторий bread2077/temp (ветка main), сохранив именно эту структуру.
   Не заменяйте папку smmprime-speed-v5: она по-прежнему нужна.
3. До замены шаблонов откройте адрес:
   https://cdn.jsdelivr.net/gh/bread2077/temp@main/assets/smmprime-speed-v12/jquery-held-v12.js
   Должен отобразиться JavaScript с началом «jQuery v1.12.4», а не ошибка.
   Проверьте также доступность app-mobile-332.webp в той же папке.
4. Замените layout целиком файлом smmprime-layout-v12.txt.
5. Замените главную целиком файлом smmprime-home-v12.txt.
6. Custom Header оставьте из v11. Custom Footer менять не нужно.

ЧТО ИЗМЕНЕНО
- Гостевая мобильная главная начинает загрузку платформенного JavaScript
  после готовности документа и предоставления браузеру возможности показать
  первый кадр. Запуск автоматический, без ожидания прокрутки или клика.
  При взаимодействии с входом загрузка начинается сразу.
- Файлы скачиваются с помощью preload параллельно, выполняются строго
  последовательно. JQuery удерживает ready до загрузки всех зависимостей
  и применения серверной конфигурации. Затем форма инициализируется.
- При нажатии Войти до готовности формы отправка удерживается и повторяется
  один раз после инициализации. При сетевой ошибке появляется кнопка повтора.
- На ПК цепочка начинает загружаться сразу после разбора её маркеров.
  Другие страницы и авторизованный кабинет сохраняют прежние подключения.
- Два полных Bootstrap CSS встроены в прежние позиции каскада: минус два
  блокирующих запроса. Частичного critical CSS и позднего применения этих
  стилей нет. Версия Bootstrap, цвета и правила оформления не менялись.
  Компромисс: HTML стал больше; CSS внутри него не кэшируется отдельно.
- Картинки приложения сжаты и получили варианты по ширине экрана/плотности.
  Mobile 332px: 11622 байта; mobile 592px: 27074 (было 35968).
  Desktop 508px: 26750; desktop 996px: 76182 (было 100320).
  Логотипы Соловов и Это развод уменьшены до ширины 100px для экранов высокой
  плотности. Главная картинка уже весит около 13 КБ и повторно не пережималась.
- Сохранены прежние правки responsive preload, Google-входа и агентного просмотра.

ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
На телефоне в приватном окне проверьте: первый экран, меню, форму входа,
Google-вход, калькулятор и подвал. Повторите проверку входа на ПК.
Затем запустите mobile PageSpeed 2–3 раза и сравните FCP/LCP и CLS.
Если форма входа не работает, верните сохранённый layout v11. Новые изображения
можно оставить, если все они доступны. Нельзя устанавливать layout v12 раньше,
чем jquery-held-v12.js доступен по CDN: от него зависит вход на гостевой главной.

ЧТО ПРОВЕРЕНО ДО ВЫДАЧИ
В jsdom выполнены реальные jQuery и платформенные скрипты из текущей страницы:
старая и новая цепочки дают одинаковый обработчик submit и ноль ошибок
инициализации. Проверено удержание ранней отправки и её однократный повтор.
Проверены синтаксис JavaScript, баланс блоков Twig, один подвал, сохранность
существующих CSS. Визуально просмотрена уменьшенная картинка приложения.
Это не браузерный тест рендеринга и не проверка авторизации на сервере:
полноценный локальный Chromium не удалось установить. Новый балл PageSpeed
ещё не измерен. Текущий mobile: 58, FCP 6.3 с, LCP 9.2 с, TBT 150 мс, CLS 0.

ОСТАЮЩИЕСЯ ОГРАНИЧЕНИЯ
Две платформенные CSS остаются внешними; все функции платформы сохранены.
Jivo остаётся в текущем виде. Google Analytics из Custom Header v11 запускается
после load на мобильной гостевой главной: короткие визиты могут не учитываться.
Не добавляйте новые inline-скрипты, требующие немедленного jQuery, на гостевую
главную без учёта новой загрузки. Итог 90/100 заранее не гарантируется.
